# Shared website files

- `modules/`: balance, Finance and clarification helpers; reusable disabled config
  example; balance setup guide. The published template remains **Petty Cash Modules**.
- `receipts/`: image-to-PDF JavaScript, complete generated Web Template and guide.
- `identity/`: **Petty Cash User Context** Web Template.
- `shell/`: existing Header/Footer templates, canonical shell CSS/JavaScript and
  shell/Home setup guide.
- `styles/`: canonical common page CSS and UI refresh guide.

These are local development folders. Keep the existing Liquid include names.
Generated HTML embeds its assets; no new Web Files or tenant folders are required.
See [README](../README.md) for build commands and publishing destinations.
