# Project documentation

Start with [HANDOVER.md](handover/HANDOVER.md) and the
[acceptance checklist](handover/HANDOVER_CHECKLIST.md).

| Folder / guide | Purpose |
|---|---|
| `handover/` | Architecture/deployment guide, operations runbook, checklist, documentation audit, implementation log and verification reports |
| `platform/` | Dataverse mappings and explicit Power Pages Web API field settings |
| `originals/` | Three original Word documents and their historical correction record |
| `corrected/` | Preserved earlier corrected Word/PDF pairs; these remain historical references |
| `backups/` | Preserved original document backups, ignored by git |
| `qa/` | Preserved local render/browser evidence, ignored by git |
| `plans/` | Deferred data-freshness proposal; no additional flow is currently planned |
| `archive/` | Retired page/admin experiments, previous README and historical Finance repair helper |
| [PROJECT_STRUCTURE.md](PROJECT_STRUCTURE.md) | Folder rationale, cleanup details and preservation checks |

Page-specific guides live beside their sources under [pages/](../pages/README.md).
Shared-template guides live under [shared/](../shared/README.md), and flow guides
under [flows/](../flows/README.md).

Local tests and a complete documentation set do not replace native exports or
company acceptance. The Word/PDF documents were not rewritten or re-rendered
during folder organization.
