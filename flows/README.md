# Power Automate flows

| Folder | Material |
|---|---|
| `finance/` | Finance flow setup, flowchart, self-posting restriction and cash-request JSON schema |
| `approval/` | Manager/boss flow guide, clarification handoff plan, review findings, received flow/trigger JSON and snapshots |
| `clarifications/` | Notification and answer-flow setup; received answer trigger, result and queue snapshots |
| `diagnostics/snapshots/` | Read-only Callback Registrations output supplied during trigger troubleshooting |

Supplied JSON is preserved byte-for-byte. Names containing `current` identify
the originally supplied files; they do not guarantee that a snapshot matches
the latest deployed flow. Refer to dated setup/runtime notes and obtain fresh
native exports for company handover. These JSON fragments are not automatically
importable complete flows.

Temporary test flows created in the tenant are managed in Power Automate, not
deleted by local file cleanup. Their shutdown remains a native checklist item.
